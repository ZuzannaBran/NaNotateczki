# Kontrola v2, rejestracji i fontów — 14 listopada 2026

Plan z 9 listopada jest historyczny. Bieżąca aplikacja ma już operacyjny
edytor, Share, namespace kont, import Local, planner CAS, ustawienia,
backup formatu 3 i sekwencję shutdown. Nie trzeba budować tych usług ponownie.

## Naprawione

- Rejestracja zwracała 404, ponieważ klient używał `/v1/auth`, a wdrożenie
  udostępnia `/v2/auth`. Klient używa teraz wyłącznie v2 także dla refresh,
  logout, zmiany hasła, zegara i raportów. Puste żądanie rejestracji v2
  zwracało 422 zamiast 404; nie zakładano konta użytkownika w trakcie kontroli.
- Pobrano kanoniczny serwer `8440fc4`: usunięte modele i importer snapshotów,
  migracja 0017 i adresy v2 są odzwierciedlone w `server/`. Własna dodatkowa
  regresja HTTP sprawdza v2 oraz brak aliasów v1, bez tworzenia kont.
- Usunięto klientowy cutover snapshotów i jego wywołania przy starcie.
  Historyczny receipt jest odrzucany. Pozostał wyłącznie odczytowy guard
  niewysłanej starej kolejki; nie importuje ani nie nadpisuje danych.
- Lokalne `com.example.program/data/local/notes.sqlite` sprawdzono tylko
  do odczytu: 0 dokumentów, 0 stron, 0 operacji, 0 wpisów outboxu. W typowych
  katalogach Dokumenty/Documents nie znaleziono dawnych plików notatek.
  Nie usuwano nowej bazy v2, credentiali ani danych innych aplikacji.
- Przed pierwszą klatką, także w Share Web, ładowany jest dotychczasowy font
  Material Icons. Nie zmieniono symboli ani ikon na inne. Test pikseli
  rozróżnia ikonę plusa od kwadratu; bez ładowania fontu test jest czerwony.
  Ten sam test dołączono do istniejącej macierzy platformowej.
- Interfejs preferuje Georgia, następnie dołączony Gelasio. Osiem odmian
  Gelasio pozostaje w assetach, niezależnie od fontów systemu i internetu.
  Pakowanie WWW odrzuca brak MaterialIcons/Gelasio oraz puste pliki fontów.
- Poprawiono kompilację testu SQLite na Web przez warunkowy import natywnego
  helpera. Poprzedni CI miał 16/17 zaliczonych zadań; jego błąd Web wynikał
  z importu FFI w teście, a nie z nieudanego testu Linux.
